# Learning Map

This project is also a practical software-engineering course.

## How lessons work

For each major feature:

1. Understand the business problem.
2. Draw the control flow in plain language.
3. Identify the files involved.
4. Read the code line by line.
5. Run it.
6. Break it deliberately in a safe environment.
7. Observe the failure.
8. Fix it.
9. Record what was learned.

## Pace

Lessons should be small enough to understand on a phone. When a topic is difficult, we split it into smaller lessons instead of skipping it.
